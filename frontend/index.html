Draw an Area on the Map

Use the rectangle tool in the top-left corner of the map to select the exact terrain you want to analyze. The system will search for the best pond locations only inside that selected rectangle. No place-name geocoding is required for this mode.

Start typing a village, town, city, landmark, road or other mapped place. Select a suggestion to move the map there, then draw the rectangle around the exact terrain you want to analyze.

You may draw the geographical area you want to analyze. Larger selections automatically use a coarser computational grid when necessary. DEM and generated contour files are processed temporarily and are not automatically saved.
